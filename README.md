## What it does

`main.py` writes a single funny line pitching a terrible pizza topping — the
Regret Special, topped with cold baked beans and a single anchovy that stares
at you like it knows what you did — to `entry.txt` in the output directory
read from `MAKEFUN_OUTPUT_DIR` (falling back to `/output`). Python standard
library only, fully deterministic: the same line every run.
